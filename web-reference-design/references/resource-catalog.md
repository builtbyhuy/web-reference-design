# Web design resource catalog

A task-routing snapshot of **75 resources in 25 categories**. Use these links as candidates to inspect, then choose resources for the project content, audience, stack, and constraints. Their order follows the source collection and is not a quality ranking.

Curated source: **Lê Huy Thái**, [shared post](https://www.facebook.com/share/p/1DFyA18XUt/) and [original post](https://www.facebook.com/lehuythaidotcom/posts/pfbid02d6XtgyvmyxisPFKcXiD5cdyWkr2j17smJABCEdnoG6UxSemUmywscJtBWxmeXWdAl). Captured **2026-10-09**, **Asia/Bangkok**.

The resource URLs and original Vietnamese group names preserve the collected index. The English descriptions and task tags are new summaries. Facebook post text, comments, and images are not included.

The snapshot is a discovery aid. Check current service availability, licenses, attribution requirements, pricing, and integration compatibility on shortlisted official sources before using code or assets. No pricing, free-tier, or license claims from the original collection are carried forward.

Machine-readable counterpart: [catalog.json](catalog.json). The lookup helper can read a selected Markdown reference library; see [library-resolution.md](library-resolution.md) for source selection.

## 01. Adaptable page blocks

Original category: Lấy mẫu có sẵn về custom

Start from reusable sections and adapt them to the project content and visual direction.

- [OriginKit](https://www.originkit.dev/) — Browse ready-made sections as starting points for a custom page.
- [21st.dev](https://21st.dev/) — Explore component examples and implementation prompts for interface work.
- [shadcnblocks](https://www.shadcnblocks.com/) — Find section patterns for marketing pages and adapt their structure.

## 02. Visual templates and AI prompts

Original category: Chọn mẫu đẹp, lấy prompt cho AI

Use visual examples to make a precise build brief before generating an interface.

- [Layers](https://www.getlayers.ai/) — Review visual templates and associated prompts for interface generation.
- [MotionSites](https://motionsites.ai/) — Study page templates that emphasize animation and motion direction.
- [Aura templates](https://www.aura.build/templates) — Browse templates to establish a page direction and adapt it in a builder.

## 03. Ready-made visual effects

Original category: Hiệu ứng có sẵn cho website

Identify focused effects for text, backgrounds, and interactive sections.

- [React Bits](https://reactbits.dev/) — Explore React examples for animated text, backgrounds, and interactive elements.
- [Aceternity UI](https://ui.aceternity.com/) — Inspect component examples with decorative backgrounds and interaction effects.
- [Magic UI](https://magicui.design/) — Use effect-oriented interface examples as implementation references.

## 04. Interface component libraries

Original category: Nút, menu, bảng có sẵn

Choose a component foundation compatible with the existing stack.

- [shadcn/ui](https://ui.shadcn.com/) — Reference editable component patterns for forms, menus, and data presentation.
- [daisyUI](https://daisyui.com/) — Explore Tailwind-oriented component classes and theme patterns.
- [Flowbite](https://flowbite.com/) — Inspect Tailwind component patterns and their interactive behaviors.

## 05. Website layout inspiration

Original category: Tìm bố cục đẹp cho website

Compare page composition, information hierarchy, and placement of content.

- [Land-book](https://land-book.com/) — Compare website layouts and section composition across visual examples.
- [Lapa Ninja](https://www.lapa.ninja/) — Study landing-page arrangements for copy, imagery, and sections.
- [Curated Design](https://www.curated.design/) — Browse selected sites to explore alternative page structures.

## 06. Visual style and user flows

Original category: Tìm phong cách và cách người dùng thao tác

Find references for the desired style and the sequence of user actions.

- [Siteinspire](https://www.siteinspire.com/) — Explore website examples to define a coherent visual style.
- [Dark Design](https://www.dark.design/) — Study dark interfaces and how they balance text, color, and imagery.
- [Mobbin](https://mobbin.com/) — Inspect application screens and user-flow references for interaction decisions.

## 07. Consistent icon families

Original category: Icon đồng bộ, giao diện gọn hơn

Use one icon family with a consistent weight and visual vocabulary.

- [Lucide](https://lucide.dev/icons/) — Inspect an outline icon family for navigation and interface controls.
- [Phosphor Icons](https://phosphoricons.com/) — Compare icon weights and styles within a single family.
- [Heroicons](https://heroicons.com/) — Choose interface symbols from coordinated outline and solid styles.

## 08. Fonts and type pairing

Original category: Chọn font và phối chữ dễ hơn

Find readable fonts and reference combinations that support the content.

- [Google Fonts](https://fonts.google.com/) — Explore font families, language coverage, and web typography options.
- [Fontshare](https://www.fontshare.com/) — Browse typefaces and inspect their suitability for project text.
- [Typewolf](https://www.typewolf.com/) — Study examples of typeface combinations used in website designs.

## 09. Palette and interface color

Original category: Chọn màu và thử lên giao diện

Test palette choices in backgrounds, text, and controls before implementation.

- [Coolors](https://coolors.co/) — Generate and compare palettes for a project color direction.
- [Realtime Colors](https://www.realtimecolors.com/) — Preview how selected colors behave in an interface-like composition.
- [Radix Colors](https://www.radix-ui.com/colors) — Reference structured color scales for light and dark interfaces.

## 10. Illustration families

Original category: Hình minh họa cùng một phong cách

Select related illustrations that communicate content with one visual style.

- [unDraw](https://undraw.co/illustrations) — Explore illustrations with adjustable color for content and interface sections.
- [Storyset](https://storyset.com/) — Browse themed illustration sets and customization options.
- [Humaaans](https://www.humaaans.com/) — Compose illustrated people and scenes from a coordinated set.

## 11. Generated backgrounds

Original category: Tạo nền theo màu của website

Create a background asset that fits the page palette and composition.

- [Haikei](https://haikei.app/) — Generate abstract shapes and wave compositions for background assets.
- [SVG Backgrounds](https://www.svgbackgrounds.com/) — Browse configurable vector background patterns.
- [fffuel](https://www.fffuel.co/) — Explore generators for vector textures, shapes, and patterns.

## 12. Content photography and video

Original category: Tìm ảnh và video cho nội dung

Find relevant visual media and inspect asset-specific usage conditions.

- [Unsplash](https://unsplash.com/) — Search photographs that fit the page subject and composition.
- [Pexels](https://www.pexels.com/) — Find photography and video clips for content or backgrounds.
- [Pixabay](https://pixabay.com/) — Explore media across photography, video, and illustration formats.

## 13. Device and presentation mockups

Original category: Đặt giao diện vào khung thiết bị

Present interface screenshots inside a suitable device or scene.

- [Shots](https://shots.so/) — Create presentation images around interface screenshots.
- [MockupBro](https://mockupbro.com/) — Place artwork or screenshots into mockup templates.
- [MockUPhone](https://mockuphone.com/) — Frame interface screenshots in device mockups.

## 14. Rendered 3D illustration assets

Original category: Ảnh 3D có sẵn, dùng như ảnh thường

Use rendered 3D graphics when an image is sufficient for the design.

- [Shapefest](https://shapefest.com/) — Browse rendered 3D objects and shapes for visual compositions.
- [Icons8 Illustrations](https://icons8.com/illustrations) — Explore illustration collections, including rendered 3D styles.
- [3dicons V1](https://old.3dicons.co/) — Inspect a collection of rendered 3D icons for feature illustrations.

## 15. Interactive 3D on the web

Original category: Đưa 3D tương tác lên website

Choose an embedding approach for an interactive model or product scene.

- [Spline](https://spline.design/) — Explore visual authoring and web embedding for interactive 3D scenes.
- [model-viewer](https://modelviewer.dev/) — Reference a web component for displaying and rotating existing 3D models.
- [Vectary](https://www.vectary.com/) — Explore 3D scene and product-configuration presentation workflows.

## 16. 3D models, materials, and lighting

Original category: Nguyên liệu để dựng cảnh 3D

Source the models, surface textures, and lighting assets a scene needs.

- [Poly Haven](https://polyhaven.com/) — Explore 3D models, surface materials, and environment lighting assets.
- [ambientCG](https://ambientcg.com/) — Find surface textures and environment assets for 3D scenes.
- [Kenney Assets](https://kenney.nl/assets) — Browse stylized game-oriented objects and scene assets.

## 17. Animated icons and illustrations

Original category: Hình và icon chuyển động có sẵn

Find motion assets with a clear role in feedback or explanation.

- [Lucide Animated](https://lucide-animated.com/) — Inspect animated icon implementations for React interfaces.
- [Lordicon](https://lordicon.com/) — Browse animated icon assets and their integration options.
- [Rive Marketplace](https://rive.app/marketplace/) — Explore interactive animation assets and runtime integration needs.

## 18. Animation libraries

Original category: Điều khiển chuyển động bằng mã

Select a motion library for specific transitions or scroll interactions.

- [GSAP](https://gsap.com/) — Reference animation controls for timelines and scroll-linked interactions.
- [Motion](https://motion.dev/) — Explore interface animation APIs and transition patterns.
- [Anime.js](https://animejs.com/) — Inspect JavaScript animation examples for text, shapes, and interface elements.

## 19. Experimental interaction references

Original category: Xem hiệu ứng lạ và học cách làm

Study unusual interactions and understand the technique before adapting it.

- [CodePen](https://codepen.io/) — Inspect public frontend experiments and runnable technique demonstrations.
- [Codrops](https://tympanus.net/codrops/) — Study frontend tutorials and demos for visual interaction techniques.
- [Hover States](https://www.hoverstat.es/) — Browse distinctive interactive websites as visual references.

## 20. shadcn theme configuration

Original category: Đổi màu, đổi font cho web đồng bộ

Align colors and typography through a coherent component theme.

- [tweakcn](https://tweakcn.com/editor/theme) — Preview and configure a shadcn-oriented interface theme.
- [ZippyStarter Theme Generator](https://zippystarter.com/tools/shadcn-ui-theme-generator) — Generate a coordinated color theme for shadcn/ui.
- [shadcn.io Theme Generator](https://www.shadcn.io/theme-generator) — Inspect theme previews and generate shadcn/ui configuration.

## 21. Type scale and spacing

Original category: Chọn cỡ chữ và khoảng cách

Define consistent text hierarchy and responsive spacing values.

- [Type Scale](https://typescale.com/) — Explore type hierarchy values based on a chosen scale.
- [Utopia](https://utopia.fyi/) — Generate fluid type and spacing values for responsive layouts.
- [Modular Scale](https://www.modularscale.com/) — Calculate a proportional scale from a base size and ratio.

## 22. Image preparation

Original category: Chỉnh ảnh gọn trước khi lên web

Prepare appropriately sized, optimized visual assets for the page.

- [Squoosh](https://squoosh.app/) — Compare image compression settings and inspect the visual tradeoff.
- [iLoveIMG](https://www.iloveimg.com/) — Inspect tools for resizing, cropping, and batch image operations.
- [Photopea](https://www.photopea.com/) — Use a layered image-editing workflow for more detailed asset changes.

## 23. Representative sample data

Original category: Thêm dữ liệu mẫu cho web bớt trống

Populate prototypes with clearly labeled sample content to test realistic density.

- [Mockaroo](https://www.mockaroo.com/) — Generate structured sample records for tables and prototype data.
- [DummyJSON Products](https://dummyjson.com/docs/products) — Reference product data for prototype catalogs, lists, and cards.
- [DiceBear Playground](https://www.dicebear.com/playground/) — Generate coordinated avatar samples for account interfaces.

## 24. Loading, empty, and error states

Original category: Cả lúc đang tải, chưa có dữ liệu và lỗi

Design feedback and recovery for incomplete, absent, or invalid data.

- [React Loading Skeleton](https://github.com/dvtng/react-loading-skeleton) — Reference skeleton placeholders while React interface data loads.
- [PatternFly Empty State](https://www.patternfly.org/components/empty-state/) — Inspect empty-state patterns that explain context and offer a next action.
- [GOV.UK Error Summary](https://design-system.service.gov.uk/components/error-summary/) — Reference form-error summaries and links to fields needing correction.

## 25. Accessibility and responsive checks

Original category: Kiểm tra web trước khi gửi link

Check contrast, usability signals, and layout behavior before sharing the page.

- [WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker/) — Check contrast between foreground and background colors.
- [WAVE](https://wave.webaim.org/) — Inspect automated accessibility findings for follow-up manual review.
- [Chrome DevTools Device Mode](https://developer.chrome.com/docs/devtools/device-mode) — Inspect layouts with device emulation and responsive viewport controls.
